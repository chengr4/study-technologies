# Model Evaluation

## Accuracy

number of correct predictions / total number of predictions

### Constraint of Accuracy

「精確率 (Precision)」和「召回率 (Recall)」與「準確率 (Accuracy)」的關係，是評估機器學習模型性能時**最核心但也最容易混淆**的部分。

簡單來說，準確率是**整體**指標，而精確率和召回率是**針對「正例」類別**的更細緻、更有針對性的指標。

以下是它們之間的詳細關係和區別：

---

## 1. 準確率 (Accuracy)

準確率衡量的是模型**整體**判斷正確的比例。

* **定義：** 模型正確預測的樣本數（無論是正例或負例）佔**總樣本數**的比例。
* **公式：**
    $$\text{Accuracy} = \frac{TP + TN}{TP + FP + FN + TN}$$
* **關注點：** 它關注模型**「整體上」**有多少比例的預測是正確的。

### 準確率的限制

在大多數情況下，準確率是一個好的起點，但它有一個嚴重的限制，尤其是在面對**資料不平衡 (Imbalanced Data)** 的問題時：

假設一個電子郵件分類系統中有 100 封郵件，其中 99 封是正常郵件（負例），只有 1 封是垃圾郵件（正例）。

| 實際 | 預測 | 數量 | 術語 |
| :---: | :---: | :---: | :---: |
| 正常 (負) | 正常 (負) | 99 | TN |
| 垃圾 (正) | 垃圾 (正) | 0 | TP |
| 正常 (負) | 垃圾 (正) | 0 | FP |
| 垃圾 (正) | 正常 (負) | 1 | FN |

如果您的模型**將所有郵件都預測為「正常郵件」**：

$$\text{Accuracy} = \frac{0 (TP) + 99 (TN)}{100} = 99\%$$

您的模型準確率高達 **99%**，看起來非常好。**但實際上，它完全沒有識別出任何垃圾郵件 (TP=0)，對您的目標（找到垃圾郵件）毫無用處。**

這就是為什麼在資料不平衡的情況下，我們需要使用 **精確率** 和 **召回率** 來取代或補充準確率，因為它們能更真實地反映模型對目標類別（本例中的「垃圾郵件」）的識別能力。

---

## 2. 精確率、召回率 與 準確率的關係

| 指標 | 關注焦點 | 衡量了什麼？ |
| :---: | :---: | :---: |
| **準確率 (Accuracy)** | **所有樣本** | 整體正確率，但容易被**數量大的類別 (TN)** 影響而失真。 |
| **精確率 (Precision)** | **預測為正的樣本** | 模型預測為正時的**「查準」能力** (排除了多少 **FP 誤報**)。 |
| **召回率 (Recall)** | **實際為正的樣本** | 模型找出實際正例的**「查全」能力** (排除了多少 **FN 漏報**)。 |

### 總結來說：

* **準確率** 是 TP 和 TN 在總數中的比例。它包含了所有四個項 $(TP, FP, FN, TN)$。
* **精確率** 只考慮了模型**預測為正**的樣本，衡量了預測結果的**品質**，不理會那些被漏掉的正例 (FN) 和被正確識別的負例 (TN)。
* **召回率** 只考慮了**實際為正**的樣本，衡量了模型對正例的**覆蓋度**，不理會那些被誤判的正例 (FP) 和被正確識別的負例 (TN)。

在您的情境「**低召回率、高精確率**」中：

1.  **高精確率** $\implies$ **低 FP** (模型預測很精準，誤報少)。
2.  **低召回率** $\implies$ **高 FN** (模型錯過了很多實際正例，漏報多)。

因為 $\text{Accuracy} = \frac{TP + TN}{Total}$，所以您的準確率會受到 $FP$ 和 $FN$ 的影響：

* 如果您的資料集**絕大多數是負例 (TN 很多)**，那麼即使 $FN$ 很高 (低召回率)，只要 $TN$ 夠大，準確率仍然可能很高。
* 如果您的資料集是**平衡的**，那麼高 $FN$ (低召回率) 和低 $FP$ (高精確率) 可能會導致準確率處於一個**中等水平**，因為正確的預測 $(TP+TN)$ 相對中性，不如精確率和召回率那樣極端。

因此，**準確率不足以判斷一個模型是否成功**；必須結合精確率和召回率，根據業務需求來確定模型的優劣。

useful measure based on the confusion matrix

- Recall: 召回率衡量的是模型找出所有實際正例的能力 (sensitivity)
- Precision: 精確率衡量的是模型在所有正向預測中的準確性
- F1 Score: Precision 和 Recall 的調和平均數

當一個模型是低召回率、高精確率時，它意味著：

模型只在有「極高把握」的情況下才會做出正向預測。

適用情境
這種模型通常適用於以下情境：「誤報 (FP)」的成本遠高於「漏報 (FN)」的成本。

垃圾郵件過濾：

高精確率：確保被標記為垃圾郵件（預測為正例）的郵件中，極少數是正常郵件（低 FP，防止誤刪）。

低召回率：意味著許多垃圾郵件會被漏掉，進入收件箱（高 FN）。

取捨：將一封正常郵件誤判為垃圾郵件並自動刪除（高成本）比讓一封垃圾郵件進入收件箱（低成本）更難以接受。

線上推薦系統：

高精確率：確保推薦的商品/內容（預測為正例）是你真正感興趣的（低 FP，避免使用者看到大量不相關內容而感到厭煩）。

低召回率：意味著系統可能錯過許多你會喜歡但未被推薦的商品/內容（高 FN）。

取捨：確保推薦的品質（精確）比確保涵蓋所有可能的選項（召回）更重要。
